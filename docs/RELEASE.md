Auroria’s main Paper plugin with town and nation management, diplomacy, vassals, tributaries, war systems, banking, bounties and territory refineries.

- Download **milzzynodes.jar** for the server. Install Vault and place both plugins in `plugins/`.
- Download **Auroria-Nodes-dev.5.11-Source.zip** for the source, original build base, compile dependencies and tests.
- Server startup, admin command registration, battle help and refinery help were checked on Paper 1.21.11 build 132 and Paper 26.3 build 256.
